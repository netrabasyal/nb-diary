# iOS release

**Deferred.** NB Diary ships as a web app in V1 (see ADR-002). This file will hold the App Store
plan when that phase starts: Codemagic cloud Mac builds, automatic signing with an App Store
Connect API key, TestFlight, versioning and build numbers, privacy disclosures, screenshots and
review requirements. Check Apple's current guidelines at that point.

Until then, the iOS project in `apps/mobile/ios` is kept compiling but is not built or signed.
