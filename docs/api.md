# API

Base path `/v1`. Errors use RFC 9457 problem details. Lists use cursor pagination.
The OpenAPI document is generated by the API (`/openapi/v1.json` in Development).

## Implemented

| Method | Route | Auth | Purpose |
| --- | --- | --- | --- |
| GET | `/health/live` | None | Process is up. Returns `Healthy`. |
| GET | `/health/ready` | None | Database reachable. `Healthy` (200) or `Unhealthy` (503). No details. |
